# Test-task
Запус:
Вариант первый:
Скопируйте ссылку и откройте её в браузере https://dolkir.github.io/Test-task/.

Вариант второй:
Скачайте репозиторий c GitHub используя кнопки Code - DownloadZip и распакуйте архив.
Откройте файл index.html двойным кликом.

Вариант третьий: 
Используйте команды:
git clone https://github.com/DolKir/Test-task.git
cd Test-task
Затем откройте index.html двойным кликом.

Вариант четвертый:
Скачайте репозиторий c GitHub используя кнопки Code - DownloadZip и распакуйте архив.
Откройте папку проека через VS Code.
Установите расширение Live Server.
Нажмите правой кнопкой на index.html и выберите Open with Live Server.
