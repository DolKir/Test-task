# Test-task

## Запуск:
### Вариант первый Онлайн:
Скопируйте ссылку и откройте её в браузере https://dolkir.github.io/Test-task/

### Вариант второй через Архив:
1. Скачайте репозиторий c GitHub используя кнопки **Code -> DownloadZip** и распакуйте архив.
2. Откройте файл `index.html` двойным кликом.

### Вариант третьий через Git: 
Используйте команды:
```bash
git clone https://github.com/DolKir/Test-task.git
cd Test-task
```
Затем откройте `index.html` двойным кликом.

### Вариант 4. Через VS Code и Live Server

1. Скачайте репозиторий: **Code → Download ZIP** и распакуйте архив.
2. Откройте папку проекта в VS Code.
3. Установите расширение **Live Server**.
4. Нажмите правой кнопкой мыши на `index.html` и выберите **Open with Live Server**.
